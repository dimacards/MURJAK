# Проект MURJAK: статическая витрина бренда одежды

## Что это
Статический сайт-витрина бренда одежды. Покупка — через переход в Telegram
продавца из карточки товара. **Без базы данных, без бота, без бэкенда** —
только готовые файлы. Категорий нет, работник один.

> История: раньше проект был на Next.js + Supabase (БД + Storage) + Telegram-бот
> на Vercel. Из-за блокировок Vercel/Supabase в РФ всё перевели на статику с
> хостингом в России. Бот, БД и Supabase удалены.

## Технологии
- **Next.js 16** (App Router, TypeScript) — статический экспорт (`output: "export"`).
- **CSS Modules** — стили (тёмная тема по макету Figma).
- Товары — в `data/products.json`; фото/видео — в `public/`.
- Сборка `npm run build` → папка `out/` (готовые HTML/CSS/JS + ассеты) → на
  статический хостинг (Beget).

## Данные и структура
- `data/products.json` — массив товаров. Поля: `id` (число), `name`, `price`
  (рубли), `inStock` (bool), `photos` (`{url, kind}`, kind=`MODEL`/`ITEM`),
  `videoUrl` (путь или null), `features` (строки), `createdAt` (ISO).
- `public/products/<товар>/` — фото и видео; `public/brand/` — лого, иконки,
  текстура, `hero.mp4` (фон главной).
- `lib/products.ts` — читает JSON (`getAllProducts`, `getProduct`).
- `app/page.tsx` — главная (hero + сетка); `app/products/[id]/page.tsx` —
  страница товара (`generateStaticParams` для экспорта).
- `config.json` — `storeName`, `sellerUsername`, `currency`, `heroVideoUrl`.

## Сайт (тёмная тема)
- Главная: hero (фоновое видео `config.heroVideoUrl` + логотип с
  mix-blend-difference) → секция «Товары» (фильтр вещь/модель, сетка карточек).
- Карточка: карусель медиа (фото + видео) + инфо-блок (название, цена, features,
  кнопка «Написать продавцу»). При `inStock=false` — плашка «нет в наличии».

## Как редактировать / деплоить
- Добавить/изменить товар: правка `data/products.json` + медиа в
  `public/products/<товар>/`. Подробно — в `КАК-РЕДАКТИРОВАТЬ.md`.
- Деплой: `npm run build` → залить содержимое `out/` на хостинг.

## Принципы работы
1. Работай этапами, между этапами останавливайся и жди подтверждения.
2. Не делай больше, чем просят в текущем этапе.
3. Не хватает информации — спроси, не догадывайся.
4. Весь текст на сайте — на русском.
5. Сайт статический: никакого серверного кода, БД, API, секретов.
