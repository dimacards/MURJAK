# Как редактировать сайт MURJAK

Сайт теперь **статический**: нет базы, нет бота. Все товары и медиа лежат
прямо в проекте. Ниже — что где и как менять.

---

## 📁 Что где лежит

| Что | Файл / папка |
|---|---|
| **Список товаров** (название, цена, особенности) | `data/products.json` |
| **Фото и видео товаров** | `public/products/<товар>/` |
| **Фоновое видео на главной (hero)** | `public/brand/hero.mp4` |
| **Логотип, иконки, текстуры** | `public/brand/` |
| Настройки магазина (имя, ник продавца, валюта) | `config.json` |

## 🎬 СЕЙЧАС: докачать 2 видео

Фото уже на месте, а 2 видео нужно скачать. Открой **Терминал** на Маке,
вставь по очереди эти команды (скачают сразу в нужные папки):

```bash
curl -L -o "/Users/dimaaristov/Desktop/Сайт_MURJAK/public/products/futbolka/video.mp4" "https://cdn.murjak.ru/storage/v1/object/public/products/products/5/video-1781380310225.mp4"
```

```bash
curl -L -o "/Users/dimaaristov/Desktop/Сайт_MURJAK/public/brand/hero.mp4" "https://cdn.murjak.ru/storage/v1/object/public/products/brand/hero.mp4"
```

После этого все медиа на месте.

## ➕ Как добавить новый товар

1. **Создай папку** для фото товара:
   `public/products/<имя-товара>/` (латиницей, например `hoodie`).
2. **Положи туда** фото и видео. Имена — любые, например:
   `model-1.jpg`, `item-1.png`, `video.mp4`.
3. **Открой** `data/products.json` и добавь блок товара в список
   (скопируй существующий и поменяй значения):

```json
{
  "id": 2,
  "name": "Худи",
  "price": 12990,
  "inStock": true,
  "photos": [
    { "url": "/products/hoodie/model-1.jpg", "kind": "MODEL" },
    { "url": "/products/hoodie/item-1.png", "kind": "ITEM" }
  ],
  "videoUrl": "/products/hoodie/video.mp4",
  "features": [
    "Состав: 80% хлопок, 20% полиэстер.",
    "Оверсайз."
  ],
  "createdAt": "2026-06-17T12:00:00.000Z"
}
```

Пояснения к полям:
- **id** — уникальное число (у каждого товара своё).
- **kind** — `MODEL` (фото на человеке) или `ITEM` (сама вещь).
- **videoUrl** — путь к видео, или `null` если видео нет.
- **inStock** — `true` есть в наличии / `false` плашка «нет в наличии».
- **createdAt** — дата; новые товары с большей датой идут первыми.
- Пути в `url` всегда начинаются с `/products/...` (это папка `public`).

> Запятые и кавычки важны — формат JSON. Если сомневаешься — просто скажи
> мне «добавь товар такой-то», я впишу сам.

## ✏️ Изменить / убрать товар
- Изменить цену/название/особенности — правишь его блок в `data/products.json`.
- Убрать товар — удаляешь его блок (и папку с фото в `public/products/`).
- Поставить «нет в наличии» — меняешь `"inStock": false`.

---

## 🚀 Как выложить изменения (после правок)

1. Собрать сайт:
   ```bash
   npm run build
   ```
   Готовый сайт появится в папке **`out/`**.
2. Залить содержимое **`out/`** на хостинг (Beget) — пошагово настроим вместе.
